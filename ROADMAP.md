# Feuille de route SIOVerse

Cette liste fixe l’ordre des prochains développements. Après chaque lot, le prochain choix est proposé parmi les éléments encore ouverts. Les petits éléments compatibles peuvent être regroupés ; les chantiers structurants sont traités séparément.

## Centre de notifications

- [x] Application dans la barre des tâches, compteur non lu et rafraîchissement automatique.
- [x] Notifications pour les ressources, contrôles, invitations, comptes et commentaires de mèmes.
- [x] Lecture individuelle et action « tout marquer comme lu ».
- [x] Réglages personnels par catégorie, enregistrés avec le compte.

## Explorateur de ressources avancé

- [x] Sélection multiple de fichiers.
- [x] Déplacement, téléchargement ZIP et suppression en lot.
- [x] Meilleure prévisualisation Office, images, code et archives.
- [x] Indication « nouveau depuis ma dernière visite ».

## Agenda amélioré

- [x] Vue journée en plus de la vue semaine.
- [x] Cours annulés, déplacés ou modifiés mieux distingués.
- [x] Association d’un cours avec sa matière et ses ressources.
- [x] Affichage des contrôles directement dans l’emploi du temps.
- [x] Widget du prochain cours plus complet sur le bureau.
